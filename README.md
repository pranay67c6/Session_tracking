Experiment 08 – Session Tracking

📌 Description

This project demonstrates session tracking in a web application using Python. It includes user registration, login, and session management.

✨ Features

User registration
User login and authentication
Session creation and management
Session-based user tracking
🛠️ Technologies Used

Python
Flask
HTML and CSS
📂 Project Files

"app_session.py" – Main application file
"app_cookies.py" – Cookie-based tracking
"templates/" – HTML templates
"requirements.txt" – Required dependencies
🚀 How to Run

Download or clone the repository.
Install the required dependencies: pip install -r requirements.txt
Run the application: python app_session.py
Open the local URL displayed in the terminal.
🎯 Objective

To understand how session tracking maintains user information across multiple requests in a web application.
